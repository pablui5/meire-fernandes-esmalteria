# Meire Fernandes Esmalteria

Site da esmalteria, especializada em blindagem e estética das unhas, mãos e pés.

É uma página única em `index.html`, sem etapa de build.

Para colocar os dados da loja, edite a variável `LOJA` no fim do `index.html`:

```js
var LOJA = { whatsapp: '5511999999999', endereco: '...', horario: '...' };
```

O WhatsApp leva só números, com DDI e DDD.
